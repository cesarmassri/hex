# Hex Survivor

Juego arcade minimalista hecho en HTML5 Canvas, CSS y JavaScript puro.

## Controles

- Teclado: `←` / `→` o `A` / `D`.
- Celular: tocar el lado izquierdo o derecho de la pantalla.
- `Espacio`: volver a empezar desde la pantalla inicial.

## Nota

Es un juego original inspirado en la idea general de los arcade geométricos de supervivencia.
No usa nombre, música, gráficos ni código de Super Hexagon.
